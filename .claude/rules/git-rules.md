

# Git 규칙
- [중요] 커밋 메시지는 한글로 사용
- [중요] 커밋전에 반드시 린트 실행
- 브렌치 명 : feature/기능명, fix/버그명
- 커밋은 작은 단위로 나눠서
- **커밋 메시지**: 한국어로 작성하되, 간결하게
- **브랜치**: main 브랜치에서 작업
- **예시**:
  ```
  계산기 appendNumber 함수 구현
  계산기 버그 수정: 소수점 중복 입력 방지
  ```

# 작업 방식
- 파일 수정 전 변경 계획을 먼저 설명
- 한번에 너무 많은 파일을 수정하지 말 것
